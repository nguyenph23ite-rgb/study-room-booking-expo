# Study Room Booking App

A React Native application built with Expo for browsing study rooms, booking time slots, and managing reservations.

## Requirements

- Node.js
- Bun
- Expo Go or an Android development build

## Setup

1. Clone the repository.
2. Run `bun install`.
3. Run `bun start`.
4. Scan the QR code with Expo Go.

## Tech Stack

- React Native
- Expo
- TypeScript
- React Navigation
